01
Fundamentos de VBA4–5 horas
Editor VBA (Alt+F11)
Onde você escreve todo o código. Módulos, ThisWorkbook, planilhas específicas. Interface do ambiente de desenvolvimento.
Sub, Function, variáveis
Dim x As Long / String / Double. If/Then/Else, For/Next, Do While. Estrutura básica de qualquer macro.
Referência a células
Range("A1"), Cells(1,1), ActiveSheet, Worksheets("Base"). Leitura e escrita de valores nas planilhas.
MsgBox e InputBox
Diálogos simples. Base conceitual antes de partir para UserForms completos.
' Exemplo: lê leitura bruta, calcula cota piezométrica, escreve resultado Sub TesteConversao() Dim leitura As Double Dim cotaInst As Double Dim CF As Double leitura = Range("B2").Value ' dígitos do PE-BT-01 cotaInst = 732.16 ' cota de instalação CF = 0.1738 ' fator de calibração Range("C2").Value = cotaInst + (leitura * CF) / 9.81 MsgBox "Cota calculada: " & Range("C2").Value End Sub
02
UserForms — pop-up de lançamento8–10 horas ← FOCO
UserForm é o componente mais crítico da Fase 1. É ele que cria o pop-up de login e o pop-up de lançamento. Dedique a maior parte do tempo aqui.
Inserir UserForm (VBE → Insert)
Painel visual de design. Arrasta controles da Toolbox: TextBox, ComboBox, Label, CommandButton.
Controles essenciais
TextBox (digitação), ComboBox (lista suspensa de instrumentos), Label (título), CommandButton (OK / Cancelar).
Eventos do UserForm
UserForm_Initialize (carrega lista ao abrir), CommandButton_Click (executa a ação), TextBox_Change (valida em tempo real).
Mostrar e fechar
UserForm1.Show para abrir, Unload Me ou Me.Hide para fechar. Diferença entre modal (bloqueia) e modeless.
' Pop-up de lançamento — botão Confirmar Private Sub btnConfirmar_Click() Dim leituraBruta As Double Dim instrumento As String Dim resultado As Double instrumento = cmbInstrumento.Value leituraBruta = CDbl(txtLeitura.Value) If Not IsNumeric(txtLeitura.Value) Then MsgBox "Digite um número válido.", vbExclamation Exit Sub End If resultado = ConverterLeitura(instrumento, leituraBruta) Call GravarNoBanco(instrumento, leituraBruta, resultado) Call ExibirStatus(instrumento, resultado) Unload Me End Sub
03
Eventos de planilha e proteção3–4 horas
Workbook_Open
Executa ao abrir o arquivo. Chama o UserForm de login automaticamente antes de liberar o acesso.
Worksheet_Change
Dispara quando uma célula muda. Atualiza gráficos automaticamente após cada gravação no banco.
Sheet.Protect / Unprotect
O código desprotege, grava o dado e protege novamente — tudo invisível. O leiturista nunca acessa células diretamente.
lastRow e VLookup
Cells(Rows.Count,"A").End(xlUp).Row+1 para próxima linha. WorksheetFunction.VLookup() para buscar CF e cota_inst da CONFIG.

01
Tabelas estruturadas (ListObjects)2 horas
O banco de dados PRECISA ser uma tabela estruturada (Ctrl+T). Ela cresce automaticamente quando novas linhas são adicionadas, e os gráficos vinculados atualizam sozinhos.
Criar tabela com Ctrl+T
Converte um range em tabela com nome. Novas linhas adicionadas pelo VBA entram na tabela e atualizam gráficos automaticamente.
Referência estruturada
=TBL_BANCO[Valor_Convertido] ao invés de =B:B. Mais robusto quando a planilha cresce ou colunas mudam de posição.
ListObjects no VBA
Worksheets("Base").ListObjects("TBL_BANCO").ListRows.Add — adiciona linha nova na tabela pelo código de forma limpa.
Filtro automático
O engenheiro filtra por instrumento ou período direto na tabela. Sem precisar de VBA adicional para isso.
02
Gráficos dinâmicos vinculados à tabela3–4 horas
Gráfico de linha temporal
Eixo X = Data, Eixo Y = Cota Piezométrica. Vinculado à tabela: nova leitura → gráfico cresce automaticamente.
Linha horizontal de controle
Série de dados constante = Cota de Atenção. Adicionada como 2ª série, formatada em laranja tracejado.
Formatar gráfico via VBA
ActiveChart.SeriesCollection(1).Format.Line.ForeColor.RGB = RGB(200,0,0). Muda cor automaticamente em alerta.
Chart.SetSourceData
Alterar a fonte de dados do gráfico pelo VBA quando trocar de instrumento na visualização.
O que NÃO precisa estudar agora: Power Query, Power Pivot, LAMBDA, fórmulas matriciais. Quem processa é o VBA — o Excel serve como interface, banco e visualização.
